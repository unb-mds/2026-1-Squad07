# Squad SDD/TDD

## Fluxo

1. Leia `AGENTS.md` na raiz.
2. Leia `specs/AGENTS.md`.
3. Leia `.specify/memory/constitution.md`.
4. Identifique a issue GitHub relacionada.
5. Verifique se a spec possui `spec.md`, `plan.md`, `test-plan.md`, `tasks.md` e `quickstart.md`.
6. Garanta que testes ou validações aparecem antes das tarefas de implementação.

## Regras

- Marque ambiguidades como `NEEDS CLARIFICATION`.
- Separe R1 demonstrável, R2 completa e futuro.
- Não invente contratos de API, banco ou UI sem evidência no projeto.
- Prefira mudanças pequenas e rastreáveis.
- Use PT-BR com acentuação correta.

## Saída Esperada

- Spec clara e verificável.
- Plano de TDD presente.
- Tarefas rastreáveis à issue.
- Critérios de aceite testáveis.
