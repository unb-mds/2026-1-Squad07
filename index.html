    CrivoAI

    Bem-vindo à documentação do CrivoAI, projeto desenvolvido pelo Squad 07 para apoiar o monitoramento da qualidade técnica de proposições legislativas.

    Visão Geral

    O CrivoAI é uma plataforma web para avaliar a qualidade técnica de proposições legislativas. O sistema automatiza o diagnóstico de clareza, legibilidade, ambiguidade e consistência normativa de textos de leis, fornecendo feedback instantâneo e inteligente para assessores legislativos, analistas e cidadãos.

    Na Release 2 (R2), o CrivoAI evoluiu de um fluxo meramente demonstrativo para um motor de análise real integrado com IA, operando com NLP e LLMs sob demanda.

    Problema

    Textos legislativos costumam ser longos, prolixos e de difícil interpretação técnica. Isso dificulta a identificação rápida de problemas formais de redação (como vagueza ou ambiguidade), referências cruzadas incorretas ou complexidade sintática que prejudique a leitura de um projeto de lei.

    O CrivoAI resolve isso aplicando técnicas de inteligência artificial para extrair insights acionáveis a partir de textos brutos, gerando resumos explicativos e listando alertas específicos de qualidade de redação técnica.

    Solução (Release 2 Consolidada)

    A plataforma organiza o ciclo de vida de análise e transparência legislativa em torno de recursos reais:

    • Análise Baseada em NLP: Classificação multi-label em tempo real com o modelo LegalBERT-pt ajustado, identificando ocorrências de: ambiguidade, vagueza, falta de referência e inconsistência.
    • Cálculo de Score de Legibilidade: Implementação nativa do algoritmo Flesch-Kincaid adaptado para a língua portuguesa, gerando notas de facilidade de leitura baseadas em estatísticas textuais (contagem de frases, palavras e sílabas).
    • Sumarização por IA Generativa: Integração assíncrona com a API do Google Gemini para produzir resumos executivos curtos, claros e acessíveis para cada lei submetida.
    • Interface Interativa e Destaques: Sidebar interativa com scroll-to-highlight dos trechos problemáticos identificados pela análise e suporte completo a Dark Mode.
    • Segurança e Perfil: Cadastro e login seguros integrados por token JWT com gerenciamento de informações na tela de perfil do usuário.
    • Dashboard Estatístico Real: Painel com indicadores globais de qualidade, médias de scores e identificação de submissões críticas do acervo.

    Fluxo de Uso do Sistema

    O CrivoAI oferece a seguinte experiência:

    1. Catálogo e Visão Geral: O usuário explora o dashboard inicial com dados reais do acervo consolidado e das submissões recentes.
    2. Submissão Segura: O usuário realiza login de forma segura e submete um texto legislativo.
    3. Processamento Inteligente: O backend FastAPI executa a análise de legibilidade, infere problemas usando o LegalBERT-pt e aciona a API do Gemini para gerar o resumo explicativo.
    4. Persistência: Os dados de lei e todos os históricos e caches de análises são gravados no banco PostgreSQL (via Prisma ORM).
    5. Navegação Analítica: O frontend Next.js exibe a página detalhada da lei, onde o usuário visualiza o resumo, o score de legibilidade e navega interativamente pelos problemas técnicos destacados no próprio texto original.

    Como Executar Localmente

    Para desenvolvimento e demonstração local:

    1. configure as variáveis de ambiente conforme os arquivos .env.example;
    2. suba backend e banco com Docker;
    3. aplique o schema Prisma quando necessário;
    4. suba o frontend com npm run dev;
    5. abra a documentação com mkdocs serve.

    As instruções detalhadas de cada área ficam nas páginas específicas de arquitetura, requisitos, specs e validação.
