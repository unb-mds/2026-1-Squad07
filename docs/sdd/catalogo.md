## Critério para adicionar uma spec ao catálogo

Uma spec só deve entrar como ativa quando possuir:

- `spec.md`;
- `plan.md`;
- `test-plan.md`;
- `tasks.md`;
- `quickstart.md`;
- status claro;
- issue relacionada.
